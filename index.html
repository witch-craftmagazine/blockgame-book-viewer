Engine Capabilities

Engineered for fidelity, accessibility, and modular embedding.

I

Authentic Vanilla Parity

Pixel-exact line wrapping calculated from Java Edition source code: 114px text boundary, 14 lines per page, 9px line height, and 1px glyph padding.

II

Multi-Format Parser

Native parsing and export for Stendhal (.stendhal), BookCopy JSON, CMI BookExport, URL hashes, and in-game /give commands.

III

Resource Pack Engine

Dynamic support for Vanilla 16x, Lithos 32x HD, server packs like Craftadia (custom emoji fonts, ranks, icons), and drag-and-drop zipped resource packs.

IV

Accessible DOM Overlay

Canvas typography is paired with an invisible ARIA live region and native selectable text for screen readers (VoiceOver, NVDA) and clipboard copying.

V

Modular Plugin API

Extend the engine with custom glyph renderers, click hitboxes, animations, and ambient backdrop sync.

VI

Web Component Ready

Embed anywhere using standard HTML: <minecraft-book src="..." view-mode="double"></minecraft-book> with responsive auto-fitting.
